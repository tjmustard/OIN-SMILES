### Lane 3 — winding residual: a principled refusal
`OIN_CANONICAL_ETA_WINDING`, default OFF. **Its target was wrong and it said so.** For 5 of 6
residuals the generated structure re-encodes byte-identically to the *mirrored* input, so the
question is "is mirror(M) the same compound as M?" and the answer differs per molecule:
GAMJAG and MECJOU achiral → fixed; SIMDIE, TEYXEA, WUHRIB chiral → input and generated are
**enantiomers**, correctly untouched. So `winding_star_drift` goes **6 → 2, not → 0**;
**driving it to 0 would fold enantiomers.** Four of six are the *generator* building the wrong
enantiomer, faithfully reported by the encoder.
Its first implementation *did* fold them (sorting the winding characters — the Y2 bug again);
an independent oracle (`tools/eta_core_chirality.py`) caught it. Per-fragment sense factor `eps`
is measured, not assumed: `+1` for TiCat3/4, `-1` for SIMDIE/MECJOU.

### Lane 4 — axial: overturned its own charter, and retired a trusted guard
`OIN_EMIT_AXIAL` stays default OFF (product call), now guarded by a test. Made the descriptor
perception-independent.
- **The generator DOES hold both hindered axes** (measured). The charter's premise — that it

  coupled pair.

## The finding that reframes the release

`docs/RENUMBERING_INSTABILITY_v0.4.5.md`. On a 225-molecule seed-42 sample (223 encoded, 2
trials/transform, levers OFF):

| | count | share |
|---|---:|---:|
| byte-stable | 125/223 | 56.1% |
| drifted | 98/223 | 43.9% |
| **comparison KEY changed** | 47/223 | **21.1%** |
| **absolute stereochemistry changed** | 29/223 | **13.0%** |

`rotate` produced **zero** drift across the whole sample — the encoder is fully
orientation-invariant. Every defect is an **atom-numbering** dependence.

The 13% is a **soundness** defect: the strings are byte-identical once `@`/`@@` are deleted, so
the neighbour ordering is the same and the tags denote genuinely different configurations — at
least one of each pair is wrong. Verified by hand on `FEQFIS_comp_0` (identical sorted
coordinate multiset, a pure permutation).

**Consequence: "100% round-trip accuracy" is not currently well-defined**, because round-trip
success is partly a property of the input file's atom order. Determinism is a precondition for
measuring it.

Capstone arm, 6,719 molecules: passing (byte_exact + key_equal) = **93.51%**; gap = **436
molecules = 6.49%**.

**The speed goal and the accuracy goal are aligned** for the dominant class — 70% of the gap is
`hard_fail` and half of that is timeouts, so speed converts a timeout into a pass or a fast
informative failure.

### ⚠ 100% is arithmetically unreachable — corrected 2026-07-25 with a measured number

I previously called `encode_fail` (11.0% of the gap) "genuinely attackable." **That was wrong.**
The correction is measured — `docs/ENCODE_FAIL_v0.4.5.md` on `swimlane/v045-encodefail`:

| of the 48 `encode_fail` molecules | count | verdict |
|---|---:|---|
| **boron / carborane cages** | **34** | **permanently unfixable** |
| quinoid / ylide kekulization | 3 | deferred; needs a deeper charge-reperception fix |
| resonance / UA-pairs timeout cohort | ≤10 | encoder-side, unresolved |
| `ASISAX` | 1 | now encodes, but **not** canonical — moved bucket, not closed |
| `HOCVAY`, possibly others | ≥1 | **dataset-mislabelled** — encodes fine; a generation-side OOM |

RDKit's **2-centre-2-electron valence model has no Lewis structure for a 3-centre-2-electron
borane cage.** The charge sweep already spans −6..+6 and finds nothing, so this is not a
tolerance to widen — it needs multi-centre bonding, i.e. a different bond model. **An encoder
that refuses those inputs is behaving correctly, not failing.**

That makes 34/6719 = **0.51% of the corpus a permanent ceiling** for a valence-graph encoder.

**Remaining honest assessment:** the timeout half of `hard_fail` (~35% of the gap) is genuinely
attackable and is the same work as the <30 s goal; `facmer_divergent` (2.8%) is a bounded
generator-selection fix; `structural` (16%) is a research problem — near the covalent-radius
+ 0.45 Å cutoff, bond perception can return a genuinely different graph for input vs generated
geometry, which the handoff names as the deepest risk (though `OIN_STABLE_METAL_AC` has now
root-caused one mechanism inside it). Realistic path: **~97–98%**.

Also note `ASISAX`: the fix makes it *encode* but it still drifts under renumbering, so it moved
from `encode_fail` into the renumbering-unstable population rather than being closed. Counting it
as a win would be double-counting a molecule that is still wrong.

The largest identified unclaimed perf prize: **eta is 23.3% of molecules but 35.6% of wall
clock** and ~3× slower at equal atom count (not a size artifact — eta molecules are *smaller*).
Cause is the haptic machinery: the `scales_for_haptic` 4× sweep (`generator3d/embed.py:1094`,
`:1208`), the widened winding pool (`metallogen_adapter.py:1311`), and the C++ batch path
refusing haptic (`embed.py:1297`). Estimated upper bound ~23% off total runtime. Untouched.

**`slot_renumber → ~0` is not reachable at that seam, and this is measured.** **32/32** residual

not `(0 1)`). The wider fold that would close it is specified in `docs/CANONICAL_SLOTS_v0.4.5.md`

and would over-fold the 7 molecules below.
