# Kulik TMC Dataset (data-only branch)

This is a **data-only** branch of the [OIN-SMILES](https://github.com/tjmustard/OIN-SMILES)
project. It carries the **tmCAT** and **tmPHOTO** transition-metal-complex datasets curated by
the **Kulik Group (MIT)** — shared here as a homage to their work — and the two shell scripts
used to drive OIN-SMILES round-trip testing over them.

➡️ **See [`tmCAT-tmPHOTO_xyz_dataset/README.md`](tmCAT-tmPHOTO_xyz_dataset/README.md)** for the
dataset description, file format, citation, and how to run the round-trip test (the library and
harness live on the `main` branch, not here).

**Citation:** Kevlishvili, I.; St. Michel, R. G.; Garrison, A. G.; Toney, J. W.; Adamji, H.;
Jia, H.; Román-Leshkov, Y.; Kulik, H. J. *"Leveraging natural language processing to curate the
tmCAT, tmPHOTO, tmBIO, and tmSCO datasets of functional transition metal complexes."* Faraday
Discussions, 2025, 256, 275–303. DOI: [10.1039/d4fd00087k](https://doi.org/10.1039/d4fd00087k)
